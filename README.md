# Деревья

## Что нужно сделать:

1. Напишите класс BinaryTree, который реализует основные операции бинарного дерева: вставка (insert) и поиск (search)
1. Напишите функцию для обхода бинарного дерева в ширину (Breadth-First Search, BFS)
1. Напишите три функции для обхода бинарного дерева в глубину (Depth-First Search, DFS): прямой обход (preorder), симметричный обход (inorder) и обратный обход (postorder)
1. Напишите класс AVLTree, который наследует класс BinaryTree и добавляет операции балансировки при вставке элементов. Реализуйте методы для поворотов (left_rotate, right_rotate) и балансировки (rebalance)
