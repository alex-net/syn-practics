# Линейный поиск и сложности алгоритмов

## Что нужно сделать:

1. Реализуйте алгоритм линейного поиска на языке Python. Функция должна принимать список и элемент для поиска, и возвращать индекс элемента или -1, если элемент не найден
1. Проанализируйте временную и пространственную сложность алгоритма линейного поиска. Объясните ваши выводы
1. Создайте список из 100 случайных чисел и выполните линейный поиск для нескольких различных значений. Запишите результаты
1. Сравните время выполнения линейного поиска для разных размеров списков (например, 10, 100, 1000 элементов). Постройте график зависимости времени выполнения от размера списка
