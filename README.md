# Простые алгоритмы сортировки

## Что нужно сделать:

1. Реализуйте алгоритм сортировки пузырьком на языке Python. Функция должна принимать список и возвращать отсортированный список
1. Реализуйте алгоритм сортировки выбором на языке Python. Функция должна принимать список и возвращать отсортированный список
1. Сравнение алгоритмов: Сравните время выполнения двух алгоритмов сортировки (пузырьком, выбором и вставками) на одинаковых списках. Постройте график зависимости времени выполнения от размера списка для каждого алгоритма
